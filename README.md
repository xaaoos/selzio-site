# SELZIO

Сайт SELZIO о горизонтальном внедрении ИИ через AI‑напарников сотрудников и об услуге разработки бизнес‑сайтов.

## Страницы

- `index.html` — главная страница «ИИ Агенты»;
- `sites.html` — страница «Вебсайты»;
- `harada.css` — стили главной страницы и окна 3×3;
- `openwindow.js` — восемь направлений и попапы главного окна;
- `sites.css` — стили страницы сайтов;
- `agent.css` и `agent.js` — интерфейс публичного AI‑напарника;
- `server.mjs` — статический сервер и API AI‑напарника;
- `assets/` — логотип, фотографии хиро и скриншоты сайтов.

## Запуск

Требуется Node.js 20 или новее.

```bash
cp .env.example .env
npm start
```

По умолчанию сайт открывается на `http://localhost:8765`. Без ключей в `.env` статические страницы работают, но ответы AI‑напарника и автоматическая отправка заявки в Telegram недоступны.

Настройка API и заявки описана в [AGENT_SETUP.md](AGENT_SETUP.md).

## Актуальные продуктовые решения

- Основная аудитория — собственники и руководители компаний численностью до 100 сотрудников.
- Главный вопрос сайта: «Как внедрить ИИ в процессы компании?»
- Главная страница построена как центральное окно 3×3 метода Open Window 64: терминальный чат SELZIO в центре и восемь направлений внедрения вокруг.
- На текущем этапе показаны только девять ячеек; внешние 64 действия не публикуются.
- Других видимых элементов на главной странице нет: каждый из восьми направлений открывается в попапе, а центральный блок уже содержит активный терминальный чат SELZIO с заголовком «Внедрение AI в процессы компании».
- Основной термин во всех текстах — `AI‑напарник`.
- AI‑напарник обладает навыками разработчика: сотрудник описывает знакомый процесс и ожидаемый результат, а напарник создаёт нужный инструмент в пределах подтверждённых прав.
- Внедрение горизонтальное: полезные решения рождаются внутри ежедневной работы сотрудников и могут распространяться среди коллег.
- Код, документация и накопленные решения остаются в компании.
- Мотивация сотрудника — сделать собственную работу легче, быстрее, точнее и содержательнее.
- Кейсы, готовые решения и сайты по технологии Easyte объединены в одной плитке главного окна; подробное портфолио сайтов находится на отдельной странице.
- Блоки с ценами на главной скрыты.
- Публичный AI‑напарник является рабочей демонстрацией подхода и помогает подготовить заявку на консультацию.

## Дизайн

- Основная и единственная тема — светлая.
- Визуальный характер: человечность, спокойствие, тепло и ощущение светлого будущего.
- Подача выстроена по принципу пирамиды Минто: сначала ответ, затем объяснение механики, пример, польза и действие.
- Фирменные акценты — тёмно‑синий фон логотипа и насыщенная жёлтая линия между смысловыми блоками.
- Кнопки единообразны; тень появляется при наведении, исходное состояние остаётся спокойным.
- Шапка обеих страниц имеет одинаковые размеры. Меню расположено слева после логотипа.
- Логотип используется без отдельной иконки. Вокруг изображения предусмотрено около 10 px синего пространства на десктопе и мобильных экранах.
- Переключатель языков визуально упрощён. Поддерживаются русский, сербский и английский языки.
- Вертикальные интервалы между связанными блоками сокращены, а внутренние отступы карточек увеличены.

Подробнее о визуальных и текстовых ограничениях — в [DESIGN_NOTES.md](DESIGN_NOTES.md).

## Git и публикация

- Репозиторий: `xaaoos/selzio-site`;
- рабочая ветка редизайна: `design/harada-inspired`;
- production размещён на собственном VPS;
- каталог сайта на сервере: `/var/www/easysite/selzio/`;
- Nginx отдаёт статику и должен проксировать `/api/` на локальный Node.js процесс.

Секреты хранятся только в `.env` или в переменных окружения сервиса. Файл `.env` не должен попадать в Git.
