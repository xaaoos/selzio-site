# Макет движения внимания SELZIO

Статус: утверждён и применяется на главной странице.

Этот документ фиксирует композиционный макет страницы. Смысловая основа находится в `DESIGN_NOTES.md`; здесь сохранено пространственное расположение блоков и маршрут переходов между ними.

## Общий маршрут

```text
ОБЕЩАНИЕ
    ↓
01 ВЫБОР РЕШЕНИЯ
    ↓
02 РЕАЛЬНАЯ ЗАДАЧА СОТРУДНИКА
    ↓

    ↓

    ↓
```

## Первый экран

Главный заголовок является первым входом взгляда. Изображение руководительницы перехватывает внимание и передаёт его вниз к тезису, действию и пояснению.

```text
┌───────────────────────┬───────────────────────┐
│                       │      ИЗОБРАЖЕНИЕ      │
│  ГЛАВНОЕ ОБЕЩАНИЕ     ├───────────┬───────────┤
│                       │ НАЧИНАЕМ  │ ВЫБИРАЕМ  │
│                       │ С ПРОЦЕССА│ МИНИМУМ   │
│                       ├───────────┴───────────┤
│                       │  ЭФФЕКТ + ДЕЙСТВИЕ    │
└───────────────────────┴───────────────────────┘
```

Три основания предложения — `процесс → минимум → эффект` — распределены по существующим плиткам первого экрана. Они не образуют отдельную полосу под хиро.

Следующий якорь: `Какое AI‑решение действительно нужно?`

## 01 — Выбор решения

Большая карточка AI‑напарника показывает фирменный метод, но соседние варианты сразу объясняют, что Selzio выбирает инструмент по задаче.

```text
┌──────────────────────────┬────────────────────┐
│                          │ CHATGPT BUSINESS   │
│       AI‑НАПАРНИК        ├────────────────────┤
│                          │ ГОТОВЫЕ ПРИЛОЖЕНИЯ │
├───────────┬───────────┬──┴────────────────────┤
│ АВТОМАТИЗ.│ AI НЕ НУЖЕН│ ВЕРДИКТ              │
└───────────┴───────────┴───────────────────────┘
```

Следующий якорь: `Откуда берётся полезная задача?`

Плитка `ChatGPT Business` выше стандартной правой карточки. Она задаёт высоту первой строки, поэтому остальные модули правой колонки продолжают её ниже единой стопкой без промежутков; большая плитка AI‑напарника слева растягивается по общей высоте первых двух строк.

## Правила изменения макета

- утверждённая геометрия макета первична: новый смысл вписывать в существующие плитки, а не создавать под него новый блок;
- сохранять один доминирующий объект в каждой композиционной группе;
- правая нижняя плитка композиции и следующий за ней переходный якорь используют один цвет, образуя единый визуальный мост; цвет выбирается отдельно для каждой пары и не унифицируется по всему сайту;
- цвет визуального моста не должен повторяться ни в одной соседней плитке этой композиции: совпадают только правая нижняя плитка и её переход;
- переходный якорь должен формулировать вопрос, на который отвечает следующий раздел;
- не добавлять декоративные плитки только ради заполнения сетки;
- не создавать внешние зазоры между bento‑модулями;
- разделять все bento‑модули одним тонким швом `1px`; соседние плитки не рисуют две линии на одном стыке;
- направление лица, рук и линий изображения должно возвращать взгляд к следующему смысловому блоку;
- на мобильном экране сохранять тот же смысловой порядок сверху вниз;
- изменения проверять тестом первого впечатления, первым кликом, глубиной прокрутки и кликами по якорям.
